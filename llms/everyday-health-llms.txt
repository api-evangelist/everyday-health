## Agent access — read this first

Everyday Health's robots.txt blocks 107 named AI and agent user-agents site-wide with
`Disallow: /`, including GPTBot, ChatGPT-User, OAI-SearchBot, anthropic-ai, Bytespider, CCBot,
Amazonbot, Applebot-Extended, xAI-Web-Crawler and YouBot, with two commercial product-review URLs
re-allowed as an explicit exception. A separately generated block lists 2,764 individual article
URLs disallowed to Google-Extended. The robots.txt preamble further asserts Ziff Davis terms of use
prohibiting text-and-data-mining, AI/ML training, fine-tuning, embedding and retrieval-augmented
generation, and directs commercial users to licensing@ziffdavis.com.

An agent that respects robots.txt cannot read this site. There is no sanctioned programmatic route
to the content other than a commercial license.

- [Ziff Davis Terms of Use](https://www.ziffdavis.com/terms-of-use)

## APIs

Everyday Health publishes no API. There is no developer portal, no API reference, no OpenAPI or
other machine-readable contract, no SDKs, no webhooks, no MCP server and no A2A agent card on any
Everyday Health host. `api.everydayhealth.com` resolves to an AWS API Gateway distribution that
answers HTTP 403 `MissingAuthenticationToken` to every unauthenticated request; it is an internal
surface with no public documentation.
